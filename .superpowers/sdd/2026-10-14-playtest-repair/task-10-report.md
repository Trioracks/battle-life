## Implementation and scope

- `src/recording-shots.js`: deterministic mic → screen → rear; first four 90 BPM beats are 8/3 active seconds, screen ends at 80%; short jobs cap mic at 40%. Reduced motion disables bob.
- `src/work-camera.js`, `src/apartment-v3-scene.js`, `src/apartment-app.js`: existing job snapshot carries elapsed seconds and shot into camera/animation/UI. Existing animation update interface retained. The persisted job is authoritative: `elapsedSeconds = job.elapsed / job.total * BEAT_RULES.workSeconds`, where `workSeconds = 8`. `advanceCreativeWork` uses the inverse `dt * job.total / 8`. Thus a 60-game-minute job at elapsed 20 is exactly 8/3 active real seconds, not 20 seconds. Paused/hidden/modal work does not advance the job; reload reconstructs the same shot.
- `src/apartment-v3-animation.js`: ordinary typing has restrained wrist/forearm taps; vocal holds the authored clip at time zero, turns torso 0.5 radians and head another 0.12 radians toward microphone, and places relaxed arms below the desktop. Only small head motion follows the same 90 BPM clock; reduced motion removes it. No vocal typing cycle or independent time counter is used when the job frame is present.
- `src/ft-studio-view.js`, `src/virtual-pc-ui.js`, `src/beat-work-view.js`: separate inert recording presentation, visible REC, musical readout/BPM, moving playhead and waveform regions from the same progress. Normal takes span 4 bars; saved 8-bar song forms retain their vocal windows via `songPartWindows`. No arbitrary 16-bar blank recording range. Rebuild/calculate project layout only on project revision/job-kind change, not every animation frame. Underlying user studio remains hidden; no play/stop/seek commands. Cancel stays above the passive overlay and hides REC.
- `tools/build-mannequin-v3.py`: reachable seated IK target, fixed 276/235 mm arm segments and horizontal hands; keyboard contact is authored, not a camera illusion. Non-seated/eat semantics preserved.
- `tools/build-apartment-v3.py`: keyboard shifted 100 mm left to align with the existing chair/root. Saucepan is a hollow 32-segment vessel on the existing front-right burner. The rear burner conflicted with the sill; controller approved the front position. Bottom is 1.010 m, grate top 1.008 m, 2 mm clearance. Handle exterior attachment no longer protrudes into the interior.
- `tools/audit-apartment-v3.py`: rejects shallow support burial, collisions of body/handle with neighbouring assemblies, and interior handle penetration.
- Tests: `test/recording-shots.test.js`, `test/work-camera.test.js`, `test/apartment-v3-animation.test.js`, `test/apartment-v3-geometry-audit.test.js`, and updated contact-amplitude assertion in `test/studio-immersion.test.js`.
