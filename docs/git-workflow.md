# Локальные ветки и контрольные точки Battle

Основная рабочая папка — D:\Project\Battle. Git уже инициализирован. С 10 октября 2026 года новые изменения разрабатываются в отдельных ветках, а master хранит проверенную основу. Настройка локальная: push и публикация не выполняются автоматически.

## Исходная контрольная точка

Ветка codex/checkpoint-pre-ft-20261010 сохраняет состояние до новой доработки FT: прежние незакоммиченные правки, исходники, тесты и пользовательские аудиофайлы. Перед снимком пройдены 449 тестов. После сохранения снимка master переводится на этот же коммит без переписывания истории; тег checkpoint/pre-ft-20261010 фиксирует точку возврата.

Скриншоты проверок в artifacts, кэши, зависимости и автоматические резервные файлы Blender исключены из новых коммитов. Они не удаляются с диска. Уже отслеживаемые Git файлы продолжают отслеживаться независимо от .gitignore.

## Новые патчи

Для текущего изменения используется codex/ft-beginner-production. Для следующих — отдельные codex/<короткое-имя-задачи> от актуального master. Коммиты небольшие и содержательные; перед коммитом проверяется состав изменений. Нельзя автоматически включать в патч посторонние файлы.

После тестов и проверки в браузере готовая ветка сливается в master через merge --no-ff, чтобы граница патча оставалась видна в истории. Незавершённая или непроверенная работа остаётся в своей ветке. Параллельная смена ветки в одной папке недопустима: она меняет файлы для всех работающих здесь процессов.

## Возврат к прежнему состоянию

Контрольные ветки и теги сохраняются. Для исправления уже слитого патча предпочтителен отдельный revert-коммит; история не переписывается. Просмотр старого состояния выполняется только после сохранения текущих правок или в отдельной рабочей копии. Автоматический reset --hard, принудительная смена ветки и удаление файлов не используются.

Git хранит версии файлов проекта, но не игровые сохранения в браузерном localStorage. Откат кода сам по себе не откатывает персонажа или проекты внутри игры. Локальная история также не заменяет резервную копию на другом диске при его поломке.
