## Сдача и судейство

Проверена настоящая цепочка доменных API: экспорт готового текста → правки Гоблина → импорт → обмен битами → запись голосом игрока → сведённый файл → импорт/обычный immutable export → upload → набор → отправка → подтверждение → закрытие → пять судей → JSON reload. Новая корректная работа изначально проходила этот путь; принадлежность бита Гоблину сама по себе сбой не воспроизвела.

Подтверждены падающими тестами и исправлены:

- Ошибка независимого расчёта судейства больше не откатывает сообщение администратора. Worker сохраняет доставленные события и передаёт предупреждение для повторения расчёта.
- Пока worker не закрыл окно, таблица показывает обработку сдач, а не объявляет «Не сдал» только по показанию часов.
- Незавершённый закрытый раунд сверяется с существующей своевременной отправкой: точные battle/round/window/version IDs, действительный сохранённый источник, участник игрока, `opensAt <= sentAt < closesAt`. Поздние/чужие/недоступные/recovery записи не принимаются. Завершённые итоги не переоткрываются.
- Если судьи уже опубликовались, недостающая работа попадает в их пакеты с исходными датами. В парном раунде старый технический отзыв соперника пересчитывается для реальной пары; неизменённые отзывы сохраняются. Нет повторных подтверждений, версий, отзывов или переброса панели после reload.

Независимый reviewer нашёл парный случай; отдельная регрессия сначала упала на `opponentTrackVersionId: null`, затем прошла после исправления. Повторное ревью подтвердило устранение P1, других подтверждённых существенных замечаний в проверенной области нет.

Оригинальное сохранение карьеры «123» не извлекалось и не запускалось. Его точная исходная причина по скриншотам не установлена; приёмка подтверждает описанные воспроизведённые механизмы и восстановление соответствующего незавершённого состояния.
