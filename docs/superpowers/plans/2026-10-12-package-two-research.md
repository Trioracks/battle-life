# Package Two — Text and Rap Dossier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Общий бюджет текста и исследование оппонентов/судей, которое расходует игровое время, остаётся субъективным и сохраняется в отдельном приложении.

**Architecture:** Чистый модуль распределения долей обогащает существующие версии текста/трека. Отдельные модели анализа и досье хранят наблюдения и источники; публичные селекторы скрывают истинные характеристики. Установка использует существующий torent/software lifecycle, время — действующий creative-work/virtual-PC runtime.

**Tech Stack:** Vanilla JS ES modules, Node built-in tests, JSON policy, localStorage, existing avatar/Web Audio/browser UI. Новое дерево навыков и внешние AI API не требуются.

**Spec:** [Пакет №2](../../backlog/2026-10-12-implementation-handoff-v2.md), [бюджет/неявки/судьи](../../backlog/2026-10-12-text-budget-noshow-and-judge-dossier.md), [темы/анализ/приложение](../../backlog/2026-10-12-round-topics-and-rap-dossier.md).

## Global Constraints

- P0 до R1. R1 выполняется до T1/T4 [плана турнира](2026-10-12-package-two-tournament.md); R2–R5 после его T5. Результаты старых версий/отчётов не пересчитываются при загрузке.
- Правила §3 постановки обязательны; численные настройки §5 и предлагаемые ниже веса анализа являются калибруемыми рабочими решениями, записываются в журнал.
- «Рэпблокнот» и «Рэп-досье» — разные приложения. Досье не даёт бонус к качеству/интеллекту и не делает закрытое публичным.
- Параметры героя брать из реального profile/metadata и существующих эффективных расчётов практики. Не заводить вторые Письмо/Интеллект. Наслушанность — учёт разнообразных изученных источников, а не новая незаказанная ветка прокачки.
- Пользовательские отчёты сохраняются независимо от установленности интерфейса досье; удаление программы не стирает знания/статистику.
- Применяются общие контракты §7 постановки, существующая граница durable save и осторожность к параллельным изменениям файлов.

## Review Focus

1. Доли превращаются в качество, сумма становится 99/101 или порог использует базовое Письмо — R1, свойственные инвариантам тесты 24/25 и практика.
2. Ошибка оценки/повторное открытие раскрывает истинный стат или даёт повторный опыт — R3/R5, тесты публичной проекции и дедупликации.
3. Старый отчёт меняется вслед за ростом героя — R3/R4, снимки навыков, история версий, перезагрузка.
4. Досье открывает будущие отзывы/чужие закрытые профили — R2/R4/R5, отрицательные тесты доступа по одной общей политике.
5. Несдачи теряются при удалении приложения/переходе раунда или одна личность дублируется в ролях — R2/R4, участие/роль/статистика после переустановки.
