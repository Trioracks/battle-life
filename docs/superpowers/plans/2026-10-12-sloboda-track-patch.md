> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Довести путь от создания текста и бита до сохранённой сдачи аудиоработы на баттл, включая согласованные правки ПК и квартиры.

**Architecture:** Четыре подплана дают проверяемые результаты. Модели этапов владеют опытом и результатом, контроллер цепочки — последовательностью, модель сдачи — неизменяемым снимком. Интерфейс ОС и установки остаются локальной симуляцией.

**Tech Stack:** JavaScript ES modules, DOM/CSS, Three.js, Web Audio, localStorage, Node.js `node:test`; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-10-12-sloboda-workflow-design.md`.
