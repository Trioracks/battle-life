# Social patch and release — Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for integration and superpowers:dispatching-parallel-agents for independent, non-overlapping UI tasks. Track actual evidence below; preserve all existing dirty changes.

**Goal:** Выпустить невыпущенную работу и девять новых замечаний без потери карьеры/контента.

**Architecture:** Существующие immutable domain state и игровые часы остаются источником истины. UI вызывает реальные действия; фоновые события атомарно сохраняются и питают пространственный звук. Общие модули и ревизии интегрирует основной агент.

**Tech Stack:** Vanilla JavaScript ESM, Node test runner, CSS, Web Audio, существующий renderer/WebGL.

**Spec:** `docs/backlog/2026-10-23-patch-backlog.md` (полное объединённое требование и принятые рабочие решения).

## Global Constraints

- D: для всех рабочих данных; не устанавливать зависимости/браузеры и не создавать большие кеши на C:.
- Текущий dirty checkout — продолжение работы пользователя, не исходник для reset/clean.
- Эпоха 2012, грубая low-poly графика, только существующие варианты ответов.
- Не менять календарь аудиопубликаций, повторную сдачу, сроки или оценки ради исправления UI.
- Не менять пользовательское сохранение при QA; отдельные fixtures/origin.

## Review Focus

- Старое сохранение после отправки: валидная версия и ack восстанавливаются без второго submission.
- Входящий ответ при чтении старых сообщений сохраняет позицию/черновик; закрытие/смена диалога не отправляет выбранный ответ.
- Worker не теряет подтверждения из-за проблем независимого судейства; не откатывает более новое действие UI.
- Загрузка истории не звучит; новые события при закрытом desktop слышны через позицию ПК.
- Новая оболочка блокнота сохраняет реальную работу/экспорт и не добавляет фиктивных кнопок.
