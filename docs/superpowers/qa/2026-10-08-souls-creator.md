# Souls-style creator — проверка реализации

Дата: 2026-10-08. Реализация установлена; визуальная приёмка в браузере не завершена.

- Три вкладки: внешность, одежда, характеристики; категории/имя/сводка слева, варианты на бумажной панели по центру, живой герой справа, действия внизу.
- Все варианты внешности сохранены. Выбор цвета, бороды и усов не теряется между вкладками; DOM активного варианта/цвета не заменяется при выборе.
- Оригинальный SVG-спрайт с текстовыми именами; стили только `#creator`, кириллический системный serif. Отдельный `creator-v12.css` оставляет старые стили квартиры нетронутыми.
- Один производственный controller для подтверждения: ровно 10 очков и непустое имя; повторный submit входит один раз. Отмена не пишет сохранение. Отказ localStorage не мешает войти, но показывает предупреждение.
- 25/25 целевых тестов редактора/профиля; 279/279 всего проекта на установленной сборке.

Не проверены визуально размеры 1280×720 и 640×900, реальные фокус/скролл и живой preview после масштабирования: инструмент browser/desktop automation аварийно завершает kernel. CSS адаптивной раскладки и контракты DOM проверены кодом; это не считается подтверждённой браузерной приёмкой. Реальные пользовательские сохранения не изменялись в ходе тестов.

Решение: отдельный scoped CSS вместо расширения `apartment-v3.css`, чтобы не задеть HUD. Цена: дополнительный небольшой запрос CSS. Работа над редактором выполнялась во время экспорта квартиры; цена — более крупная общая интеграционная проверка.
