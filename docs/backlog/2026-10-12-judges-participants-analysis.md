- «НАРОД» — коллективный канал/голос, не имя судьи. «ИТОГ», «Баллы», «СЧЁТ» — результаты, не персонажи.
- Во втором раунде у nedonebo заполнены только H10, H13, H39 — три единицы; у большинства остальных судей по 29 числовых значений. Поэтому наличие столбца не означает полноту голосования.
- В третьем раунде у каждого судьи по 13 числовых значений при 16 участниках. Пустые ячейки нельзя превращать в нулевые оценки.
- Голос 0 означает выбор другого участника пары; это не оценка качества «0 из 10».
- Примечания на заголовках бывают общими ремарками, шуточной шкалой или ссылкой на внешний разбор. Они не являются отзывами конкретному участнику.
- Некоторые примечания пересказывают голосовое или отправляют к подкасту. Сама аудиозапись такого разбора этим экспортом не получена.

## BL-008 — импорт раундов, участников и составов судей

**Цель:** получить устойчивые игровые записи людей, этапов и исторического судейства из источника.

### Предлагаемая структура таблиц

| Таблица | Одна строка означает | Основные поля |
| --- | --- | --- |
| Персонажи | Одного человека независимо от числа раундов и ролей | ID, отображаемый ник, варианты имени, роли, ссылки на источник |
| Раунды | Один этап турнира | ID, порядок, формат оценивания, число участников, правило прохода |
| Участие в раунде | Участника конкретного этапа | ID раунда, ID персонажа, пара/соперник, исходная строка |
| Состав судей | Назначение конкретного судьи на конкретный этап | ID раунда, ID судьи, исходный столбец, полнота данных |
| Оценки и отзывы | Решение одного судьи по одной работе/паре | Раунд, участник/пара, судья, исходное значение, тип значения, комментарий, вкладка и ячейка |
| Игровые профили | Настройки персонажа для симуляции | ID человека, судейские предпочтения/манера, отдельно музыкальные навыки, основание и статус согласования |

Таблицы могут стать листами одного будущего рабочего файла и/или игровыми данными. Окончательный формат выбрать при переходе к реализации. Эта запись не создаёт отредактированную Google-таблицу.

### Объединение имён

| cenobite / сенобит | Транслитерация |
| cyber olegi / кибер олежа | Вариант написания |
| dead rave / дед рейв | Транслитерация |
| whitespruce / вайтспрус | Транслитерация |
| kosh (SpaceCave) / кош | Вариант с указанием объединения и без него |
| BenArfa / бен арфа | Транслитерация и пробел |
| Alx Beats / алкс битс | Транслитерация |

Если подтвердить все перечисленные объединения, получится 29 судей. Это условный результат предлагаемой карты соответствий, не уже доказанное число людей.

У участников тоже есть варианты, например «Маста Витяй (Why-Fly)» / «Маста Витяй» и «Аллахов †» / «Аллахов†» / «Аллахов✝». Сохранять оригинальные строки. Не объединять похожие имена автоматически только по расстоянию между строками.

### Результат и проверка

- Каждый повторяющийся судья имеет один постоянный ID, а раунды ссылаются на него.
- Список участников доступен с привязкой к этапам; не ограничиваться финалистами.
- У каждого факта есть адрес в исходнике; данные источника отделены от игровых настроек.
- Две вкладки первого раунда не удваивают оценки и комментарии. Расхождения сохраняются отдельно для решения.
- Пропуск, числовой ноль, неучастие и технический проход не смешиваются.
- Перед использованием правил прохода разобраться с неполными голосами, коллективным столбцом «НАРОД» и историческими итогами.

## BL-009 — индивидуальные игровые профили судей

**Цель:** один и тот же человек узнаётся по вкусам и манере отзывов в разных раундах.

Судейские предпочтения и музыкальные навыки самого человека — разные наборы параметров. Оценки чужих треков не доказывают, насколько хорошо сам судья читает или сводит музыку.

### Предлагаемые игровые параметры

- Приоритет смысла/раскрытия темы и идей.
- Внимание к рифмам, панчам и структуре текста.
- Приоритет флоу, ритма, подачи, дикции и интонаций.
- Чувствительность к качеству записи и сведения.
- Значимость общего музыкального впечатления, атмосферы и оригинальности.
- Отношение к экспериментальным жанрам и нестандартной форме.
- Строгость и разброс оценок для балльных этапов.
- Манера комментариев: краткость/подробность, прямота, ирония, допустимая обсценная лексика.
- Характерные речевые обороты, длина отзыва и склонность объяснять сравнение с соперником.

Числовые веса и игровые коэффициенты пока не назначены. Срок выставления оценки тоже не выводится из источника: в экспортированных данных нет достаточных временных отметок для такого вывода.

### Первые наблюдения, не окончательные характеристики

| Судья | Наблюдение из просмотренных отзывов | Основание / ограничение |
| --- | --- | --- |
| Тридцать Третий | Развёрнутые разборы подачи, интонаций, ритма, звука и общего впечатления; текст тоже обсуждается | 1 РАУНД (СВОДНАЯ)!F34, F35, F67, F68; ФИНАЛ!C3. Можно предложить такой игровой стиль, но не точные веса |
| епархия | Часто коротко отмечает конкретную удачу или проблему текста/исполнения/звучания | 1 РАУНД (СВОДНАЯ)!B2, B35, B68, B69 |
| клим пропавший | Есть короткие ироничные отзывы; в шапке — шуточное описание шкалы | 1 РАУНД (СВОДНАЯ)!C1, C2, C35, C67. Шутки в шапке не переводить буквально в формулу |
| свиноферма | Прямые реакции на впечатление от прослушивания, понятность текста и яркие строки | 1 РАУНД (СВОДНАЯ)!E2, E34, E35, E67 |
| атака трупа | В первом раунде числовые оценки в среднем ниже остальных судей, но текстовых отзывов нет | 100 работ сводной: среднее 3,84; у остальных средние 5,88–6,90. Это наблюдение о баллах, не объяснение вкусов |

Для каждого будущего профиля сохранить несколько опорных примеров и отметить, что взято из источника, а что предложено как игровая интерпретация. Судье с двумя голосами и без комментариев не приписывать обоснованный подробный вкус наравне с человеком, оставившим сотню развёрнутых разборов.

**Результат:** реестр судей с общей идентичностью между раундами, предложенными настройками, основаниями и подтверждёнными решениями автора.

## BL-010 — оценки и комментарии для новых игровых работ

**Цель:** применять правила текущего этапа и индивидуальные судейские профили к новой работе игрока.

- Первый балльный этап и последующие парные голосования — разные режимы.
- Число и состав судей задаются конкретным этапом; не подставлять постоянных пять судей во все раунды.
- Архивные оценки и победители сохраняются как исторический источник. Не превращать их без отдельного решения в неизменный исход прохождения героя.
- Для нового трека фидбэк должен соответствовать фактическому результату и свойствам работы в игровом представлении.
- Исторические отзывы использовать для изучения манеры и тематик; случайно выдавать старый отзыв о чужом треке как разбор работы героя нельзя.
- Подготовить варианты отзывов в манере каждого судьи с разной длиной, тоном и конкретной причиной решения. Количество шаблонов согласовать отдельно; 10 ответов администратора и около 20 личных постов не являются числом судейских комментариев.
- Для парного этапа учитывать сравнение с конкретным соперником, а не только качество работы в вакууме.
- Появление оценки/отзыва становится событием для уведомлений и BL-007. Личный пост может брать реальный сформированный комментарий за основу.
- Математика, разрешение ничьих, неявки, пропуски голосов и роль «НАРОД» требуют отдельного решения.

**Результат:** судьи выставляют решения в формате этапа и дают узнаваемые, содержательно подходящие отзывы; эти события связаны со стеной и уведомлениями.

## Подтверждение автора и глубокий анализ

Автор подтвердил сохранение формата этого баттла и использование его как шаблона для генерируемых турниров. Для новых треков нужны новые комментарии с индивидуальной логикой и манерой судьи. Вопросы «сохранять ли формат» и «генерировать ли новые отзывы» закрыты.

Выполнен полный разбор письменного корпуса, включая причины сравнительного выбора, контрпримеры, длину/манеру сообщений и ограничения выводов. Основной результат: [руководство по поведению судей и генерации](2026-10-12-judge-behavior-guide.md). Оно уточняет предварительные наблюдения выше; начинать дальнейшую работу с него и подробных профилей.

## Вопросы перед игровой реализацией

1. Как включить героя в подтверждённую сетку: заменяет ли он одного участника или увеличивает число заявок? Новое прохождение требует расчёта результатов новых работ.
2. Оставляем исходные ники или создаём игровые имена? Подтвердить карту вариантов, особенно «ок» / «охуенно культурный».
3. Какой список первого раунда считать основным при расхождении 100/101? Почему «1,5 кг детских обид» отсутствует в сводной?
4. Как работает «НАРОД», разрешаются ничьи, технические проходы и отсутствие индивидуального голоса? Историческая пустота не равна обязательной игровой механике.
5. Из каких данных получать свойства новых треков, нужные для содержательного судейства: симуляция, авторская разметка, анализ текста/аудио? Общего значения quality недостаточно для детальных слуховых утверждений.
6. Из каких данных задавать навыки участников как исполнителей? Судейские отзывы и результаты не дают объективных значений навыков.

Эти вопросы не мешали анализу источника; они нужны перед окончательной настройкой игровых данных и разработкой.

## Уже подтверждённая связь с соцсетью

Сданные работы появляются в аудиозаписях сообщества **после окончания приёма работ**. Личные аудиозаписи пополняются при прикреплении, а пост на личной стене создаётся по событиям судейства. Это три разных события, их не объединять.
