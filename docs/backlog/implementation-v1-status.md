## Внешние вопросы и ограничения

- **BL-002:** нужны записи автора; ожидание относится только к этой поставке.
- **BL-001:** если происхождение ресурсов нельзя установить по проекту, нужны уточнения по конкретным файлам.
- **BL-008/BL-010:** перед запуском полной исторической сетки решить место героя, 100/101 заявку, спорные алиасы, нечётные игровые составы/роль «НАРОД» и технические проходы. Парная ничья исключена последующим решением автора; порядок равных сумм отбора остаётся техническим вопросом. Импорт и независимые механики продолжаются раньше.
- Большая библиотека, индивидуальные игровые настройки и интеграция всех составов ещё требуют работы. Четыре готовых банка не закрывают остальных судей.
