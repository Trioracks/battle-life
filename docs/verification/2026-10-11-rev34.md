## Принятые решения и ограничения

1. Продолжить без нового круга согласований по прямому поручению пользователя. Цена неверного решения — пересмотр обратимых локальных изменений.
2. Пока использовать текущий банк 90 BPM для всех открытых стилей; отдельные жанровые банки не предоставлены. Итоговое ревью подтвердило это ограничение: жанры пока могут звучать слишком похоже.
3. Историческую подборку оставить на основании доступного индексированного текста первоисточников с явными ссылками. Прямое открытие части страниц блокировалось проверкой соединения; исторические атрибуции могут потребовать уточнения при доступе к оригиналу.

Отложенная мелочь: у начатой до обновления и затем продолженной работы HUD первого этапа может показать `+0.00` жанрового опыта из-за старой исходной шкалы. Сам опыт начисляется правильно; новые этапы отображаются правильно. Будущее исправление должно отделить мигрированный исходный показатель HUD от неизменяемого аудиопрофиля.

Исходные аудиофайлы и пользовательский `stems/janres/non/vocal/test.zip` не менялись. Публикации в удалённый Git нет; рабочая ветка сохраняется для отката.
