# Battle Life

Браузерная игра о начинающем MC из Каликфорнии: создайте персонажа, живите в
квартире, работайте, следите за потребностями и готовьтесь к MAKAREWITCH VI.

Тестовая веб-версия: `0.1.0-preview.1`. После настройки и успешной публикации
она доступна по адресу [Battle Life](https://trioracks.github.io/battle-life/).
Версия и короткий SHA сборки показаны в меню; полные данные есть в `release.json`.

Музыка и вокал отключены в тестовой веб-версии. Процедурные эффекты интерфейса и
комнаты сохранены. Сохранение находится только в `localStorage` этого браузера:
оно не синхронизируется между устройствами, локальным адресом и GitHub Pages.
Не очищайте данные сайта, если хотите сохранить кампанию.

Для локального запуска нужен Node 24. В клонированной папке выполните:

```sh
npm ci
npm start
```

Откройте `http://127.0.0.1:4180/battle-life/`. Прямое открытие `index.html`
через `file://` не поддерживается. На этом Windows-компьютере сначала настройте
D: для временных файлов и кешей по [инструкции](docs/public-preview.md).

Разработка: `npm test` (Node 24 и Python 3 без дополнительных пакетов),
`npm run build:preview`, `npm run audit:source`, `npm run audit:site`.
Игра, сервер и сборка Python не требуют.

укажите SHA из меню, браузер, шаги, ожидаемый результат и приложите скриншот.
Не прикладывайте личные данные или содержимое сохранения без необходимости.
