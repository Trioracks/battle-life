# Battle Life

Браузерный MVP о начинающем MC из Каликфорнии. Игрок собирает внешность персонажа, живёт в квартире, работает, следит за базовыми потребностями, ездит по карте города, регистрируется на MAKAREWITCH VI и готовит трек к дедлайну.

Для разработки подготовлен [пакет №1 — BL-001–BL-013](BACKLOG_V1.md): [постановка и приёмка](docs/backlog/2026-10-12-implementation-handoff.md), [журнал реализации](docs/backlog/implementation-v1-status.md). Следующие идеи записываются в [новый активный бэклог](BACKLOG.md), начиная с BL-014.

## Запуск

Дважды кликните [Запустить игру.cmd](Запустить%20игру.cmd). Скрипт поднимет локальный сервер и откроет игру по адресу `http://localhost:4173`.

Не открывайте `index.html` через `file:///…`: игра использует ES-модули, поэтому прямой запуск файла может не загрузить сцену или скрипты.

Если нужен ручной запуск:

```powershell
Set-Location 'D:\Project\Battle'
F:\Python\python.exe -m http.server 4173 --bind 127.0.0.1
```

Затем откройте `http://localhost:4173`.

## Проверка

```powershell
npm test
```

Сохранение кампании находится в `localStorage` браузера. Для нового старта очистите данные сайта в инструментах браузера.
